# Research dossier: Inverted flight (half roll in, hold, half roll out)

Figure `inverted-flight` in the category `motorglider`. Access date 2026-11-24. Pages were read through the fetch tool (machine summary, not the raw text); check key statements on the live page before changing an instruction. All statements are paraphrases. **No source covers motor gliders**; the only glider remark is in RCSKY (single source). The owner has flown inverted with a motor glider; that is not a source.

## Statements

| id | Statement | Sources (groups) | Status |
| --- | --- | --- | --- |
| IF1 | Start from straight and level flight, adding some power if needed (a little above cruise). | wikipedia-rc-aerobatics, rcsky-rueckenflug (2) | CONFIRMED (`level-add-power`) |
| IF2 | Roll half a turn onto the back with the aileron. | wikipedia-rc-aerobatics, rcsky-rueckenflug, flitetest-inverted (3) | CONFIRMED (`half-roll`) |
| IF3 | Centre the aileron once the wings are level, inverted. | wikipedia-rc-aerobatics, rcsky-rueckenflug (2) | CONFIRMED (`centre-aileron`) |
| IF4 | To hold the height inverted, push the elevator forward (down elevator), a little. | wikipedia-rc-aerobatics, flitetest-inverted, rcsky-rueckenflug, rcaw-basic, stevens-pattern (5) | CONFIRMED (`hold-elevator`) |
| IF5 | Elevator and rudder work reversed from the pilot's view inverted; the aileron stays the same. | wikipedia-rc-aerobatics, flitetest-inverted, rcsky-rueckenflug (3) | CONFIRMED (`reversed`) |
| IF6 | Too much forward elevator stalls or dives the model; too little loses height. | flitetest-inverted, rcsky-rueckenflug (2) | CONFIRMED (`push-amount`, no amount) |
| IF7 | The stall speed is higher inverted; flying too slowly stalls. | flitetest-inverted, rcsky-rueckenflug (2) | CONFIRMED (`stall-speed`) |

| IF9 | Exit by rolling back, not by pulling out; pulling in a startle dives the model. | flitetest-inverted, rcsky-rueckenflug (2) | CONFIRMED (`roll-out`) |
| IF10 | Practise with enough height to recover. | flitetest-inverted, rcsky-rueckenflug (2) | CONFIRMED (`enough-height`, no value) |

## 3 Phase outline (CONFIRMED statements only)

1. Prerequisite (S12, S13, S11): plain harrier, inverted harrier, slow rolls with rudder/elevator support. Figure is advanced.
2. Set-up (S10): high rates/large travel on rudder, elevator and aileron, reduced exponential.
3. Entry (S1, S8): start from a stable nose-high harrier, full aileron one way, elevator eased slightly.
4. Roll, repeated (S3, S4, S5, S6, S7): aileron held full; rudder strongest on knife-edges, elevator does the work near upright/inverted (down toward inverted, up back toward upright); throttle trimmed to hold altitude and nose attitude.
5. Corrections (S7, S15, S16): add power when nose or airspeed drops or roll slows; timing of rudder/elevator inputs steers the drift.
6. Exit (S9): add power, release aileron, reduce elevator, return to forward flight.

## 4 Conflicts and open points

- C1 Throttle at roll start. A: add a few clicks at the start and keep it in. B: medium-to-low throttle, adjust to hold altitude. C (Greiner): cut power at full aileron, add only if the model cannot hold. Not an outright contradiction (setup/model dependent) but no agreed rule. Treat the throttle level as NOT AGREED; only "trim throttle to hold altitude/attitude" is confirmed (S7).
- C2 Torque roll before or after. C (normalfreak): learning torque roll first helps. E (Noll): harrier rolls come before torque rolls in the practice list. Do not state an order between the two.
- C3 Is rudder essential? B: elevator-only works but is worse (bad habit). C: Walli1977 and Goelfle say rudderless works roughly; sleepless says clean power rolls without rudder are not workable. A, B use rudder. Safest wording: rudder is part of the proper technique (A, B, C-majority), rudderless is a poor substitute.
- C4 Nose attitude numbers: A 35-60 degrees, B 30-60 degrees (about 45). Also A sets entry attitude at 30-35. Only the overlap (roughly 35 to 60) is common; do not present a single value as fact.
- C5 Is the figure the same as "Powerrolle"? Source C treats the two as the same in the thread title, but one user (Greiner) notes torque roll must not use aileron, and one pilot calls for torque-roll knowledge. Name equivalence rests on one source only.
- NOT FOUND: rudder direction relative to roll direction in left/right terms (A and B only describe it relative to the model's orientation: "full at knife-edge", "top rudder"); exact elevator values per phase; the proportion of rudder vs elevator at upright/inverted points beyond B's "roughly equal at 45 degrees"; throttle percentages; altitude/speed numbers; wind effects beyond A; a German-language magazine/instructor text; a manufacturer guide; any second independent source for the 1-1.5 s per roll number; how many rolls per pass; model-type (electric vs glow, wing loading) dependence beyond B's "depends on aircraft".
- NOT FOUND: any independent German source other than the single rc-network thread. German content therefore currently has one independence group.
- Open: the RCU threads, the Profile Brotherhood thread and the Model Airplane News members article could not be read; reading them would likely add independence groups for the S3 to S8 statements and settle C1.

## 5 Difficulty and category

- Advanced to pro. Evidence: B calls it the most advanced standard stalled 3D figure (single author, but stated flatly); A calls it demanding and needing a lot of practice; C (sleepless) calls clean versions advanced/champion-level. Confirmed as hard (S11).
- Learning progression (confirmed): upright harrier, inverted harrier, knife-edge, hover (B), slow rolls with rudder/elevator support (B, C), then rolling harrier. E independently places harrier rolls after harriers and before torque rolls and rolling loops (single list from Noll, so ordering vs torque roll stays open, see C2).
- Beginner suitability: no source suggests it for beginners. D requires basic aerobatics and independent rudder use even for the plain harrier.
